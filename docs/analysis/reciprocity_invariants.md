## 1. C1 — What the max-side invariant actually is

Sources read in full: Booker, *On Mullin's second sequence of primes* (arXiv:1107.3318v2), §3
including the review of Cox–van der Poorten and Lemmas 1–4; Pollack–Treviño, *The primes that
Euclid forgot* (Monthly), §§2–3 including Proposition 5 and its full proof. Cox–van der Poorten
(1968) not obtained directly, but Booker §3 opens with an explicit review of their method,
which is what is used here.

Write `R_n = q_1⋯q_n`, `N_n = 1 + R_n`, max rule `q_{n+1} = maxFac(N_n)`.

### 1.1 The two symbol laws

Booker's review states the factorisation

    (*)   1 + P_1⋯P_n = q_1^{k_1}⋯q_r^{k_r},   q_1 < … < q_r = P_{n+1}

and extracts two laws by evaluating a Kronecker symbol *in the denominator*, which is
completely multiplicative there:

* **Mod-4 law.** `N_n ≡ 3 (mod 4)`, since `R_n = 2·(odd)`. Hence
  `(-4/q_1)^{k_1}⋯(-4/q_r)^{k_r} = -1`.
* **Discriminant law.** If `d` is a fundamental discriminant with `d | R_n`, then
  `N_n ≡ 1 (mod d)`, hence `(d/q_1)^{k_1}⋯(d/q_r)^{k_r} = 1`.

Cox–van der Poorten take `d` built from *known* `P_i` and solve the system by linear algebra
over `F_2`. Booker's equivalent formulation: find a fundamental discriminant `d` composed of
known `P_i` with `(d/q) = (-1/q)` for the first several primes `q` not known to occur.

Pollack–Treviño Proposition 5 makes this explicit. With `Q_1,…,Q_r` the smallest omitted
primes, `X = 12²(Q_1⋯Q_r)²`, and `p` the last prime in `[2,X]` to appear (as `q_n`), they
choose `d ≤ X` with `d ≡ 1 (mod 4)`, `d ≡ -1 (mod Q_1⋯Q_r)`, `(d/p) = (-1/p)`, and compute the
Jacobi symbol `(d / N_{n-1})` two ways:

* **Top-down** (reciprocity, `d ≡ 1 mod 4`, `d = d_0 d_1²`, `d_0 | R_{n-1}`):
  `(d/N_{n-1}) = (N_{n-1}/d) = (N_{n-1}/d_0)·(N_{n-1}/d_1)² = 1`.
* **Bottom-up** (multiplicativity in the denominator over
  `N_{n-1} = Q_1^{e_1}⋯Q_r^{e_r} p^e`): `(d/N_{n-1}) = ∏(-1/Q_i)^{e_i}·(-1/p)^e
  = (-1/N_{n-1}) = -1`, since `N ≡ 3 mod 4`.

### 1.2 Distillation

The max-side invariant is:

> the value of a real character `χ_d = (d/·)`, whose modulus `4|d|` is built from primes
> *already produced by the orbit*, evaluated at the Euclid number `N_n`; pinned to `+1` by
> `N_n ≡ 1 (mod d)`, and simultaneously computed as a product over the prime factorisation of
> `N_n`.

The blocking mechanism is **support confinement**:

> **Support Confinement Lemma (max side).** If `p = maxFac(N_{n-1})` is the last prime `≤ X` to
> appear, every prime factor of `N_{n-1}` lies in the *finite* set `B = {Q_1,…,Q_r, p}`. A
> single real character can be made constant on a finite set of primes (this is what
> `d ≡ -1 mod Q_1⋯Q_r` and `(d/p) = (-1/p)` achieve), and then the bottom-up product collapses
> to `(-1/N) = -1`, contradicting the top-down `+1`.

Two archimedean ingredients hide inside: (i) confinement is a *size* statement (all factors
`≤ p`); (ii) `d ≤ X` is needed so all prime factors of `d` have already occurred — this is
where Burgess (Booker) or the elementary run-length bounds `ℓ'(□,p), ℓ'(⊠,p) < 2√p`
(Pollack–Treviño §2) enter.

So the reciprocity class must contain the *invariants*, but the max-side *blocking argument*
additionally consumes a non-symbol ingredient. Keep these separate; the whole assessment turns
on it.

## 2. C2 — The min-side reciprocity-enriched transition system

### 2.1 First reduction: anchored symbols are congruence invariants

For a **fixed** finite anchor set `d_1,…,d_s`, `J(d_j | ·)` is a real Dirichlet character —
Mathlib `jacobiSym.mod_right : J(a | b) = J(a | b % (4 * a.natAbs))` for odd `b`. So tracking
`(d_j / N_n)` is tracking `R_n` modulo a fixed modulus. These are literally Task A's congruence
invariants at `m' = lcm(m, 4|d_1|,…,4|d_s|)`, and Task A applies verbatim (its statement is
uniform in `m`).

**Consequence.** The Cox–van der Poorten invariant *as an invariant* is anchored, hence
congruence, hence already covered. Only its *blocking mechanism* is new. This forces the
enlargement to be about **moving moduli**.

### 2.2 The genuinely new data

Let `p_1 = 2, p_2, …` be min-orbit multipliers, `R_n = p_1⋯p_n`, `N_n = R_n + 1`,
`p_{n+1} = minFac(N_n)`. The new data is symbols whose **modulus is the new multiplier**:

    β_{ij} := log_{-1}(p_i / p_j) ∈ F_2,      ν_i := p_i mod 8.

Quadratic reciprocity gives `β_{ji} = β_{ij} + ((ν_i-1)/2)((ν_j-1)/2)`. Level-`n` symbol data:

    Σ_n = ((ν_i)_{i≤n}, (β_{ij})_{1≤i<j≤n}) ∈ ((Z/8)^×)^n × F_2^{C(n,2)}.

A genuine refinement: for each earlier orbit prime `p_i` — possibly far larger than any fixed
`m` — the datum `β_{i,n+1}` is one bit of the residue of `p_{n+1}` mod `p_i`.

### 2.3 Structural laws satisfied by the true orbit

* **Euclid unit law.** `N_n ≡ 1 (mod p_i)` for `i ≤ n`, hence `(N_n/p_i) = 1`; more strongly
  `N_n ≡ 1 (mod R_n)`.
* **Euclid parity law.** `R_n ≡ -1 (mod p_{n+1})`, hence
  `∏_{i≤n}(p_i/p_{n+1}) = (-1/p_{n+1})`, i.e. in `F_2`:
  `Σ_{i≤n} β_{i,n+1} ≡ (p_{n+1} - 1)/2 (mod 2)`.

Both hold verbatim for max. They are *laws*, not arguments; their rule-symmetry is expected and
is not a filter failure.

### 2.4 Definition of the enriched system

Pitfalls: (a) if the state remembers the actual primes, every orbit set is trivially
propagating and "invariant" is vacuous; (b) the state space grows with `n`; (c) the abstract
relation must not be so relaxed that it loses 2.3. Resolution: a **graded (ind-) system with
immutable history and existentially defined transitions**, with 2.3 imposed as axioms.

> **Definition R.** Fix an odd modulus `m`. A *level-`n` state* is
> `s = (r ; ν_1,…,ν_n ; (β_{ij})_{i<j≤n})` with `r ∈ Z/m`, subject to being **realisable**:
> there exist distinct primes `p_1 = 2 < …` with `p_i ↦ ν_i (mod 8)`,
> `β_{ij} = log(p_i/p_j)`, and an integer `R ≡ r (mod m)` with `R = p_1⋯p_n`.
>
> *Transition* `s → s'` (level `n → n+1`) holds iff there exist an odd `N ≥ 3` and a prime `π`
> with
>
> 1. `N ≡ r+1 (mod m)`, `N ≡ 3 (mod 4)`, `N ≡ 1 (mod p_i)` for `i ≤ n` *(Euclid unit law)*;
> 2. `π = minFac(N)`, `π ∉ {p_1,…,p_n}`;
> 3. `Σ_{i≤n} β'_{i,n+1} ≡ (π-1)/2 (mod 2)` *(Euclid parity law)*;
> 4. `r' = r·π (mod m)`, `ν'_{n+1} = π mod 8`, `β'_{i,n+1} = log(p_i/π)`, and all level-`n`
>    coordinates are copied unchanged **(immutability)**.
>
> A *propagating reciprocity invariant* is `S = ⨆_n S_n` with `s ∈ S, s → s' ⟹ s' ∈ S`. `S`
> *blocks* `q` iff no `s ∈ S` is `q`-forcing.

**(R1) Collapse to a growing modulus.** By `jacobiSym.mod_right` plus reciprocity, every
`β_{i,n+1}` is a function of `π mod 4p_i`, and `ν'_{n+1}` of `π mod 8`. So the entire symbol
update is a function of

    π mod Π_n,   Π_n := 8·m·p_2⋯p_n.

**The reciprocity enrichment is exactly the replacement of the fixed modulus `m` by the
orbit-dependent growing modulus `Π_n`.** The reciprocity class is not a different *kind* of
invariant; it is the congruence class with a modulus allowed to grow along the orbit.
Immutability legitimises this — old coordinates are never rewritten.

**(R2) Faithfulness.** Every true-orbit state is realisable and every true transition satisfies
1–4. The relation strictly over-approximates the orbit, which is what makes "invariant"
non-vacuous. Scope caveat: an argument using the *exact integer* `R_n` is outside this class by
construction — and outside every invariant-based class.

## 3. C3 — Do the three moves extend?

### 3.1 EVICTION — untouched. CONFIRMED.

Coprimality to `Π_n = 8m·p_2⋯p_n` is *equivalent* to coprimality to `m`: `N_n` is odd and
`N_n ≡ 1 (mod p_i)` by the unit law, so `gcd(N_n, 8·p_2⋯p_n) = 1` automatically. The orbit
primes evict themselves. Finite Hitting `|Hit(ℓ)| ≤ π(ℓ-1)` applies at the same `m` as in
Task A. **Symbol-blind; no new input needed.**

### 3.2 FULLNESS — extends, and needs only qualitative Dirichlet.

Claim: at a free level-`n` state, *every* level-`(n+1)` state compatible with the parity law is
reachable in one step.

**Construction (two primes, chosen in order).**

1. Choose the target class `u ∈ (Z/Π_n)^×` for the new multiplier. This simultaneously
   prescribes `r' = r·u mod m`, `ν'_{n+1}`, and the whole new symbol column. Require the parity
   law — one real-character condition `ψ(u) = 1`.
2. Dirichlet: pick a prime `π ≡ u (mod Π_n)`.
3. Choose the **cofactor** `M` prime with `M ≡ (r+1)π^{-1} (mod m)`, `M ≡ π^{-1} (mod p_i)` for
   `i ≤ n`, `M ≡ 3π^{-1} (mod 8)`, and any prescribed class mod `π` (this fixes `(M/π)`, the
   one genuine "spin"-type symbol). Moduli pairwise coprime; CRT + Dirichlet give infinitely
   many such `M`; take `M > π`.
4. Set `N = π·M`. Then `minFac(N) = π`, `N ≡ r+1 (mod m)`, `N ≡ 1 (mod p_i)`, `N ≡ 3 (mod 4)`.

Ordering is essential: the new prime is chosen first, *then* the cofactor realises the
moving-modulus symbol `(M/π)`. Symbols against the new modulus are congruence conditions on the
cofactor, so they cost nothing.

**Exact density statement needed.**

> **(F) Qualitative Dirichlet, CRT form.** Let `m_1,…,m_t` be pairwise coprime positive
> integers and `a_j ∈ (Z/m_j)^×`. Then there are infinitely many primes `π` with
> `π ≡ a_j (mod m_j)` for all `j`.

In Galois language this is Chebotarev for `Q(ζ_M)/Q`. The expected formulation — Chebotarev in
the compositum `Q(ζ_m, √d_1,…,√d_s)` — **degenerates to (F)**: a multiquadratic field is
abelian and sits inside `Q(ζ_D)`, `D = lcm(4|d_j|)`. **No general Chebotarev is required in the
quadratic case.**

*(For a `k`-th power-residue enlargement, `k ≥ 3`, the degeneration fails for symbols `(a/π)_k`
with `a` fixed: one needs genuine Chebotarev in the Kummer extension `Q(ζ_k, ᵏ√a)` — exactly
Booker's Lemmas 3–4. But the construction above only uses symbols with *rational* modulus,
which are congruence conditions on `π` and on `M`. So even the higher-power sub-class extends
on Dirichlet alone.)*

**Mathlib status — catalog entry T7.4 is STALE.** Dirichlet's theorem on primes in APs **is in
Mathlib**: `Mathlib/NumberTheory/LSeries/PrimesInAP.lean`, `Nat.infinite_setOf_prime_and_eq_mod`
and `Nat.forall_exists_prime_gt_and_eq_mod`. Also present: `jacobiSym.mul_left`,
`jacobiSym.mul_right`, `jacobiSym.at_neg_one`, `jacobiSym.mod_right`,
`jacobiSym.quadratic_reciprocity`, `legendreSym.quadratic_reciprocity`, `ZMod.chineseRemainder`.

### 3.3 CRT-REACH — extends, with a one-bit parity correction.

Forcing is a purely congruence condition on `r`, involving no symbol data. After FULLNESS, `S`
contains every state with `r' = r·u`, `u ∈ ker ψ`. Since `r` is a unit mod `m`, the conditions
at places dividing `q·∏_{p<q}p` pin `u` there and leave it free elsewhere. The orbit contains
primes exceeding `q` (super-exponential growth), so:

> **Parity Correction Lemma.** Because some orbit prime exceeds `q`, `ψ` is nontrivial on the
> subgroup of units congruent to `1` at every place dividing `q·∏_{p<q}p`. Hence the Euclid
> parity law never obstructs reaching a `q`-forcing state.

Independently: at a `q`-forcing state the parity law with `π = q` is *automatic*, being exactly
`(R/q) = (-1/q)`, which follows from `R ≡ -1 (mod q)`. Likewise the unit law is automatic.
**The two structural laws are implied by forcing, not in tension with it** — the sharpest way
to see why the enrichment cannot block.

### 3.4 CvdP filter, move by move

* **EVICTION**: rule-symmetric; a lemma about which primes have appeared. Not the source of the
  asymmetry; fine.
* **FULLNESS**: **rule-symmetric** — for max, choose the large prime first and the small one
  second. FLAGGED. Not a defect: fullness is a lemma about the richness of the abstract
  relation, and the relation is rich under both rules. (The specific construction
  `minFac(π·M) = π` does fail for maxFac, but its mirror image works.)
* **CRT-REACH**: **asymmetric — this is where everything happens.** `minFac(N) = q` is the
  congruence condition "`q | N` and no odd prime `< q` divides `N`", a nonempty union of
  classes mod `q∏_{p<q}p`. `maxFac(N) = q` is "`q | N` and `N` is `q`-smooth", which is **not**
  a congruence condition at any modulus: every residue class contains numbers with arbitrarily
  large prime factors. Max-side forcing states do not exist as congruence objects, "blocking"
  inverts, and the theorem does not transfer. **Filter passes with the break point isolated in
  a single definition.**

## 4. The Character Non-Constancy Lemma — why min can never block

> **Lemma.** Let `χ` be a nontrivial real Dirichlet character mod `D`. Then `χ` is not constant
> on `{primes > Y}` for any `Y`. (Pick `a, b ∈ (Z/D)^×` with `χ(a) = 1`, `χ(b) = -1`; Dirichlet
> supplies primes `> Y` in both classes.) By contrast `χ` *is* constant on suitable finite sets
> of primes, with the least such `D` boundable (Burgess / run-length bounds) — exactly Booker
> Lemma 2 and Pollack–Treviño's choice of `d`.

* **maxFac** confines the factor support of the Euclid number to a **finite** set (primes `≤ p`
  minus those already used, i.e. the omitted primes plus `p`). Characters can be constant
  there. Contradiction available.
* **minFac** confines the factor support to a **cofinite** set (primes `≥ q`). Characters are
  never constant there. No contradiction is available, for any `d`, ever.

Dynamically: **under minFac the discarded cofactor is the large part, dynamically inert and
arithmetically unconstrained; under maxFac the discarded part is the small part, which
coprimality has already forced into the finite omitted set.** The omitted primes are the
*carriers* of the max-side argument and are *invisible* on the min side.

## 5. The escalation check (run explicitly, negative)

Suppose only finitely many primes `Q_1,…,Q_r` are omitted from the **min** sequence. Take `X`
large; let `p` be the last prime in `[2,X]` to occur, `p = q_n = minFac(N_{n-1})`.

* Every prime `< p` other than the `Q_i` has occurred, hence is coprime to `N_{n-1}`.
* `minFac(N_{n-1}) = p` forces every prime factor of `N_{n-1}` to be `≥ p`, so the `Q_i` below
  `p` cannot divide `N_{n-1}` at all.
* Conclusion: `N_{n-1} = p^e·∏Q_i^{e_i}·C` with `C` composed of primes `> X`, and `C` is
  **unconstrained** (`N_{n-1}` is super-exponentially larger than `X`, so `C > 1` and its
  residues are free).

The bottom-up evaluation of `(d/N_{n-1})` now contains `(d/C)`, which no choice of `d`
controls. The argument dies here and nowhere else. **No blocking invariant; no escalation.**

## 6. C4 — Verdict, boundary, formalization plan

### Verdict: EXTENDS

**Reciprocity-class No-Invariant Theorem (min side).** *Let `m` be an odd modulus divisible by
`∏_{p≤q} p`. In the reciprocity-enriched system of Definition R, no propagating invariant
containing the min-orbit tail blocks `q`.* Proof = EVICTION (3.1) + FULLNESS (3.2) + CRT-REACH
(3.3).

**Corollary (the payoff).** Any proof that a prime is omitted from the min Euclid–Mullin
sequence must use information outside the reciprocity class — necessarily
multiplicative-anatomy or archimedean information (largest prime factor, smoothness, `ω(N)`,
explicit size of `R_n`). This *explains* Cox–van der Poorten: their essential non-congruence
ingredient is `q`-smoothness of the Euclid number, forced by maxFac.

### The boundary (what is NOT killed)

1. **Anatomy data**: `ω(N_n)`, smoothness, `P⁺(N_n)`. FULLNESS uses `N = π·M` with `ω(N) = 2`;
   a system additionally requiring `ω(N_n) → ∞` would not admit this transition. This is the
   honest gap, and where all max-side content lives.
2. **Exact-value arguments**: anything using `N_n = R_n + 1` as an integer identity rather than
   a congruence. Outside any invariant framework.
3. **Non-abelian symbol data** (Rédei symbols beyond the multiquadratic level; spin of varying
   ideals). No candidate found and no max-side witness uses any.

*Key fact.* The max-side omission proofs block a prime by making a real character constant on
the factor support of the Euclid number. `maxFac` confines that support to a **finite** set;
`minFac` confines it to a **cofinite** set, and no nontrivial real character is constant on the
primes above any bound (Dirichlet). Every min-side reciprocity invariant collapses: by
`jacobiSym.mod_right` it is a congruence invariant at the growing modulus `Π_n`, EVICTION is
automatic, and the two structural laws are *implied* by forcing rather than in tension with it.
Category **TM**, not SF — no counterexample to a stated hypothesis. Revival **0**: proves
nothing positive about MC. It is a *positive* result for the project — obstruction-killing, and
one of the few results in the corpus that is not an instance of Dead End #90.
